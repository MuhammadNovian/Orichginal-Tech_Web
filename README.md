# Orichginal-Tech_Web
Description
Orichginal Tech is a platform offering services for website development, logo design, graphic design, and other digital products. This landing page serves as an introduction to Orichginal Tech's services and provides an easy way for potential clients to get in touch with our team.

The website is designed with a modern, responsive layout that ensures it looks great on all devices (desktop, tablet, and mobile). Key features of this landing page include:

1. Hero Section: Displays the main message and call-to-action to contact us.
2. Services: Describes the services we offer, such as website development, logo design, and graphic design.
3. About Us: Provides information about Orichginal Tech and our mission.
4. Contact Us: Displays ways to reach the Orichginal Tech team via WhatsApp, Instagram, and email.
5. Scroll to Top Button: A button that allows users to easily return to the top of the page.

Key Features

1. Responsive Design: Optimized for different devices (mobile, tablet, desktop).
2. Interactive: Allows users to contact us directly via WhatsApp, Instagram, or email.
3. Smooth Scroll: Scroll-to-top button for easy navigation back to the top of the page.
4. Modern Aesthetic: Clean and minimalist design focused on user experience.

Technologies Used

* HTML5: The page structure is built with HTML5 elements.
* CSS3: Styling is done using CSS to ensure a responsive and interactive design.
* JavaScript: JavaScript is used for interactive features like the scroll-to-top button and form validation.
* SVG: SVG icons are used for crisp and scalable visuals.
